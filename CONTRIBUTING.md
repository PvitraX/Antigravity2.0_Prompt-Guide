# Contributing

PRs welcome. Here's how to add a prompt:

## Adding a Prompt

1. Find the right folder (`prompts/cli`, `prompts/subagents`, `examples/fullstack`, etc.)
2. Add your prompt in a code block with a clear title and description
3. Include: what it does, when to use it, any gotchas
4. Open a PR with the title: `[category] Add: <short description>`

## Prompt Quality Bar

A good prompt in this repo:
- ✅ Actually tested — you ran it in Antigravity and it worked
- ✅ Specific — not vague one-liners
- ✅ Includes constraints — file paths, stack, what not to touch
- ✅ Has a clear expected output

A prompt that won't be merged:
- ❌ "Write me a CRUD app" (too vague)
- ❌ Untested / theoretical
- ❌ Duplicate of an existing prompt

## Reporting a Broken Prompt

Open an issue with:
- Which prompt
- What Antigravity version you're on
- What happened vs what you expected
